# Distribution and firmware notes

This repository contains source code and documentation only. It does not
include Hyundai/Mobis firmware, OEM APK/JAR/DEX/ODEX files, system images,
emulator disks, physical head-unit backups, NEMESIS files, BusyBox binaries,
or Java/Ghidra libraries. Supply authorized target files and host dependencies
separately.

The build and ADB workflow imports utilities from the sibling
`gen5w-audio-shortcuts` repository; its license status is recorded in
`AUDIO_SHORTCUTS_PROVENANCE.json`. This notice does not grant rights to that
project or to third-party/OEM material.
